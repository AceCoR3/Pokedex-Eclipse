# Pokédex Eclipse

Minimalistischer, responsiver Pokémon-Pokédex mit animierten Pixel-Sprites, dynamischem Typ-Glow und deutschen Pokémon-Namen.

## Lokal starten

```bash
npm install
npm run dev
```

## GitHub Pages

Unter **Settings → Pages → Build and deployment** die Quelle **GitHub Actions** auswählen. Der Workflow `.github/workflows/deploy.yml` veröffentlicht anschließend die App.

## Datenquellen

- https://pokeapi.co/
- https://github.com/PokeAPI/sprites

Pokémon und Grafiken gehören ihren jeweiligen Rechteinhabern. Dieses Fanprojekt ist nicht offiziell mit Nintendo, Game Freak oder The Pokémon Company verbunden.
